Install it

  1. Click Download for classic Outlook. You get a file called Corporate Direct.htm.
  2. Close Outlook.
  3. Press Windows key + R, paste %APPDATA%\Microsoft\Signatures, and press Enter.
  4. Move the downloaded Corporate Direct.htm into that folder.
  5. Open Outlook, go to File → Options → Mail → Signatures, and pick Corporate Direct for new messages and for replies/forwards.
